# what-if → parallelpens.com

PlotTwist is now **Parallel Pens**, at **https://parallelpens.com**.

This repo only serves the old address, `https://yuvraj-dot.github.io/what-if/`. Its page sends visitors to the same page on parallelpens.com, and offers to bring along any stories they saved at the old address (browsers keep each site's saved data separate, so the old address has to hand it over).

`index.html` and `404.html` are the same file, so every old link lands on it.
